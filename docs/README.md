# Astro Console Documentation

The active product and delivery documentation is under [V2](v2/README.md).
It describes the rig-local server and its browser workspace.

Do not add credentials, private network addresses, device serial numbers,
machine paths, raw hardware evidence, or other personal observatory details.
Keep those materials under the ignored `.local/` directory instead.

The retired SDK, Electron desktop workflow, and prototype UI documentation are
available only through Git history.
