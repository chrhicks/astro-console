# Gate 1: Composite Workspace

Status: **accepted**

Gate 1 selected the shared V2 shell and workspace model represented by the
[Composite reference](../../../prototype/v2-ui/composite-prototype.html).

## Accepted Decisions

- Plan, Observe, Library, and Process are freely switchable workspaces.
- An accepted run continues independently of browser and workspace presence.
- A compact global surface keeps the active run visible everywhere.
- Wide operational layouts place evidence first and judgment or action next;
  compact layouts preserve that order when stacking.
- The shared context rail presents Inspector and attention without duplicating
  workspace commands.
- Observe hierarchy follows current state and useful decisions rather than a
  permanently visible numbered phase sequence.
- Library is chronological, evidence-oriented, and owns durable review.
- The first phone experience is intentionally read-only.

## Role In Later Gates

Gates 2–4 refined workspace-specific behavior without replacing this shell.
The shared rules are consolidated in
[V2 UX and design guidance](../ux-design-guidance.md).
