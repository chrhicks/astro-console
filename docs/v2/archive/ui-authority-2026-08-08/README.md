# Retired Astro Console UI And UX Authority

Status: **historical and non-authoritative as of August 8, 2026**

This bundle preserves the Astro Console-local visual system, component
grammar, UX catalog, and implementation guidance that preceded the official
Nightbook demo and `@nightbook/ui` adoption direction.

These files explain earlier decisions. They must not guide new UI composition,
component creation, styling, or visual review. Use
[`docs/v2/current/ui-ux.md`](../../current/ui-ux.md) and the external Nightbook
demo workspace for current UI work.

## Contents

- `ux-design-guidance.md` — former semantic UX baseline.
- `ux-user-stories.md` — former UX planning catalog.
- `visual-style-guide.md` — former local visual authority.
- `ui-component-library.md` — former local semantic component catalog.
- `ui-build-contract.md` — former local UI implementation contract.
- `legacy-component-grammar.md` — former `apps/web/src/components/PATTERNS.md`.

The existing non-beta React workspaces, styles, and local components remain in
the application only because they still serve the default routes. Their code is
not current design authority and may be retired after beta promotion.
