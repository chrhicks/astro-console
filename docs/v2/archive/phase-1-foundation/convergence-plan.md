# V2 Convergence Plan

Status: **complete — Gate 7 accepted; V2 reference frozen**

Prototype discovery ends in one validated interaction specification and one
backend-facing domain and contract model. It is not an indefinitely growing
gallery of studies.

| Gate | Status | Result |
| --- | --- | --- |
| 1. Composite workspace | Complete | Plan, Observe, Library, Process, global run context, warnings, context rail, desktop, and read-only phone |

## Gate 5 Boundary

Gate 5 translates accepted Gates 1–4; it does not reopen them. Begin with a
shared scenario set and state-ownership table. Every consequential UI action
must map to:

- eligibility and authorization;
- one named intent command;
- revision or freshness preconditions where relevant;
- a deterministic result and durable evidence;
- typed failure before physical action when invalid; and
- snapshot and event projections sufficient to drive desktop and read-only
  phone views.

## Completed Technical Spikes

Three bounded spikes are complete:

1. Catalog scale and bounded rendering.
2. Image overlays and solve geometry.
3. Streamed state and preview reconnect behavior.

Each recorded a measurement and decision without growing into a parallel
framework or reopening accepted interaction models.

## Stop Criteria

Prototype discovery stops when:

- one reference walkthrough covers planning, acquisition, capture, warnings,
  recovery, workspace switching, review, processing, reconnect, and control;
- desktop and phone consume the same canonical truth without granting phone
  mutations;
- every consequential action has a command, eligibility rule, result, and
  typed failure;
- healthy, delayed, warning, failure, recovery, reconnect, stale-client, and
  control-transfer traces execute deterministically;
- the three spikes have recorded constraints; and
- no unresolved choice can materially change the first local-web foundation.

At exit, retain the interaction specification, contracts, scenario traces,
state-ownership rules, deterministic fixtures, and accepted reference
prototypes. Archive or discard alternative layouts and prototype-only code.
