# Astro Console V1 mark package

Selected mark: **Alignment Aperture**. The symbol preserves the clipped
field-of-view observation: a primary body is cropped by the reticle while its
companion remains separate, with the center-to-observation relationship intact.

`astro-console-v1-symbol-*.svg` are the authoritative production vectors.
Use `ink` on light grounds, `light` on deep night, and `mono` only for
one-color reproduction. Minimum symbol size is 16px; maintain clear space of
one symbol radius.

The horizontal `wordmark-reference` files are approved layout references, not
deployable canonical vectors: their text still depends on Georgia/Arial
availability. Before production wordmark use, outline the lettering from the
licensed approved type source and release it as a new versioned package. This
package deliberately makes the selected symbol authoritative rather than
silently treating font-dependent text as canonical.

Artwork is project-owned; see `manifest.json` for semantic color values,
viewBoxes, licensing, and version-governance details.
