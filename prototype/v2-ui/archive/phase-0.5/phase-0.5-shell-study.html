Phase 0.5 · outer-shell inquiry

Three ways to frame the same consequential work.

This is not three themes. Each direction gives persistent context a different job: instrument panel, observing log, or field desk.

Comparison discipline

Every frame represents the same V2 evidence: an active M31 run, a current solve, freshness, controller, and a bounded next decision. The accepted interactions are unchanged; this page tests only how the shell establishes attention before the native object appears.

01 · Instrument PanelFacts and evidence form a controlled readout. 02 · Observing LogThe observing session is a temporal, living trace. 03 · Field DeskThe current visual judgment owns the surface.

Direction 01

Instrument Panel

Make the shell an operational instrument: compact labels, stable readouts, and evidence in repeatable positions. The object sits inside a quiet index rather than a generic app frame.

Best for: high-density Observe and Authority views where an operator needs to cross-check current truth fast.

Decision after walkthrough

Choose the shell behavior, not the prettiest screenshot.

The next review should put the same four accepted hard states—storage recovery, exhausted Acquire, stale authority, and failed Process stage—through the preferred direction. Keep the interaction models fixed; accept a direction only if the shell makes current truth, evidence, authority, and protected recovery clearer without becoming a generic operations dashboard.
